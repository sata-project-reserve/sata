# Devnet Runbook

1. Set `NEXT_PUBLIC_APP_MODE=devnet`.
2. Set `MAINNET_ENABLED=false`.
3. Connect a MetaMask Solana devnet account.
4. Fund the account with devnet SOL.
5. Configure SATA token inputs.
6. Generate or provide a devnet metadata URI.
7. Review token creation preview.
8. Approve each devnet transaction in MetaMask.
9. Run post-launch verification in the app.
10. Export `launch-manifest.json` and `launch-report.md`.

Do not reuse devnet signatures or addresses as proof of mainnet launch.
